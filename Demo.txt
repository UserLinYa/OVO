# 每行一个频道，格式：
#   标准频道名 | 别名1;别名2 | 分组 | 台标URL（后三项均可省略）
#
# 只要标准名或别名命中，源就会保留；不在本文件中的频道会被过滤。
# 也可以直接把源写进来（会同时加入白名单）：
#   CCTV1,http://example.com/live/cctv1.m3u8
#   CCTV1 | http://example.com/live/cctv1.m3u8
#
# 分组留空时会自动推断；台标留空时使用 config.toml 的 logo.template。
# 修改本文件即可增删频道，无需改 Python 代码。
# ============================================================================
